A 4 KB Python chess engine: alpha-beta search with tapered evaluation, history ordering and a bishop-pair bonus, packed to 3,988 bytes.

## Run it

```sh
python3 main.py
```

The engine plays through the make.fun environment server (set `MAKEFUN_ENV_URL` to the env URL, as the kit's practice harness does).
